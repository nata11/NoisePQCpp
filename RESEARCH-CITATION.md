## How to Cite

If you use this project in academic publications, theses, dissertations,
technical reports, benchmark studies, or similar scholarly outputs, please cite
the software.

Preferred citation metadata is provided in [CITATION.cff](CITATION.cff).

Suggested BibTeX:

```bibtex
@software{ahmed2026noisepqcpp,
  author       = {Ahmed, Nadeem},
  title        = {NoisePQC++: A C++23 Implementation of the Noise Protocol Framework with Post-Quantum Cryptography},
  year         = {2026},
  url          = {https://github.com/nata11/NoisePQCpp},
  version      = {1.0.0}
}
```

Suggested text citation:

> Ahmed, Nadeem (2026). _NoisePQC++: A C++23 Implementation of the Noise Protocol Framework with Post-Quantum Cryptography._ Version 1.0.0, 2026 https://github.com/nata11/NoisePQCpp

## Reproducibility Guidance

For reproducibility, it is helpful to report:

* the project version
* the release tag or commit hash
* the archived-release DOI (e.g. `10.5281/zenodo.19782169`) when citing a Zenodo-archived version
* any local modifications
* the build configuration used for experiments
